## 2. Perbedaan SH dan BASH

SH dan BASH bisa digunakan untuk menjalankan perintah di Linux.

SH merupakan Shell yang digunakan untuk menerima perintah dari user dan menjalankannya.

Sedangkan BASH merupakan salah satu jenis Shell yang lebih sering digunakan di Linux dan punya beberapa fitur tambahan.

Jadi menurut saya, perbedaannya adalah SH lebih dasar, sedangkan BASH merupakan pengembangan dari Shell dengan fitur yang lebih lengkap.

## 3. Dokumentasi Command Linux

Berikut beberapa command Linux yang saya gunakan dalam video beserta penjelasannya:

| Command | Penjelasan |
|---|---|
| `pwd` | Digunakan untuk melihat lokasi folder yang sedang saya gunakan. |
| `ls -lah` | Digunakan untuk melihat isi folder beserta informasi detail seperti permission, owner, ukuran, dan file tersembunyi. |
| `mkdir tugas-linux` | Digunakan untuk membuat folder baru dengan nama `tugas-linux`. |
| `cd tugas-linux` | Digunakan untuk masuk ke folder `tugas-linux`. |
| `touch file.txt` | Digunakan untuk membuat file baru dengan nama `file.txt`. |
| `chmod 755 file.txt` | Digunakan untuk mengubah permission dari file `file.txt`. |
| `cp file.txt backup.txt` | Digunakan untuk menyalin `file.txt` menjadi `backup.txt`. |
| `mv backup.txt data.txt` | Digunakan untuk mengganti nama `backup.txt` menjadi `data.txt`. |
| `ip addr` | Digunakan untuk melihat informasi IP dan network interface pada Linux. |
| `ss -tulpn` | Digunakan untuk melihat port dan service yang sedang listening. |
